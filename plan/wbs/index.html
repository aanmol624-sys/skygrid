The Plan · WBS

Work Breakdown Structure

The WBS should show what the project must deliver, not merely a chronological task list.

PMI defines a WBS as a deliverable-oriented hierarchical breakdown of total project scope, and emphasizes the 100% rule: the WBS includes all project work and only project work . Professor Renso’s course also emphasizes defining scope, time, cost, and project-management planning before execution .

PMI describes the WBS dictionary as the companion detail behind WBS components and control accounts as points where scope, budget, and schedule come together for performance measurement . SkyGrid will use the same WBS codes across schedule, budget, risk, responsibility, and change-control artifacts so the project does not become a collection of unrelated tables.
